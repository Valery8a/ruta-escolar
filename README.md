# Ruta Escolar

Desarrollo de una plataforma web para la gestión de rutas particulares de transporte escolar en Tunja, Boyacá.

## Descripción del proyecto

Ruta Escolar es un prototipo de plataforma web diseñado para facilitar la organización y gestión de la información relacionada con el transporte escolar particular. El proyecto busca centralizar los datos de estudiantes, conductores, rutas y asignaciones, permitiendo una administración más organizada del servicio.

## Objetivo

Desarrollar un prototipo de plataforma web que permita gestionar información de estudiantes, conductores y rutas de transporte escolar, facilitando la consulta de datos y la comunicación de novedades entre los participantes del servicio.

## Funcionalidades

- Registro y consulta de estudiantes.
- Registro y gestión de conductores.
- Creación y administración de rutas.
- Asignación de estudiantes a rutas y conductores.
- Consulta de información de las rutas asignadas.
- Registro y gestión de novedades del servicio.
- Acceso según los roles de administrador, conductor y acudiente.

## Tecnologías utilizadas

- HTML
- CSS
- JavaScript
- LocalStorage (almacenamiento local del navegador)

## Alcance

El proyecto corresponde a un prototipo académico desarrollado para pruebas locales. No cuenta con conexión a una base de datos externa, GPS en tiempo real, pagos en línea ni notificaciones automáticas.
